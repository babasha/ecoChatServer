# 📊 Сравнительный отчёт: Gemma-3-4B vs Gemma-3-12B

## Модели
- **Gemma-3-4B**: 4 миллиарда параметров
- **Gemma-3-12B**: 12 миллиардов параметров (3x больше)

## 🏆 Сводная таблица результатов

| Метрика | Gemma-3-4B | Gemma-3-12B | Изменение |
|---------|------------|-------------|-----------|
| **Скорость перевода (средняя)** | 400-728ms | 730-1986ms | 🔴 **2-3x медленнее** |
| **Batch 5 сообщений** | 1.02s (204ms/сообщ.) | 4.09s (817ms/сообщ.) | 🔴 **4x медленнее** |
| **DetectAndTranslate** | 0.89-1.18s | 2.58-3.25s | 🔴 **2.5x медленнее** |
| **Токенов/сек (средний текст)** | ~71 токенов/сек | ~24 токенов/сек | 🔴 **3x медленнее** |
| **Качество переводов** | 67% (2/3) | 67% (2/3) | 🟢 **Одинаковое** |
| **Точность переводов** | Хорошая | Отличная | 🟢 **Лучше** |

## 📈 Детальное сравнение

### 1. Тест реальных переводов (TestLMStudio_RealTranslation)

| Языковая пара | Gemma-3-4B | Gemma-3-12B | Качество 12B |
|---------------|------------|-------------|--------------|
| **English → Russian** | 728ms: "Здравствуйте, как вы?" | 1.99s: "Здравствуйте, как дела?" | ✅ Лучше |
| **Russian → English** | 421ms: "Hello, how are you?" | 887ms: "Hi, how are you?" | ✅ Естественнее |
| **Portuguese → Russian** | 505ms: "Здравствуйте, как вы поживаете?" | 787ms: "Здравствуйте, как вы?" | ✅ Короче |
| **Spanish → Russian** | 431ms: "Привет, как дела?" | 730ms: "Привет, как дела?" | 🟰 Идентично |

**Вывод**: 12B модель дает более естественные переводы (например "Hi" вместо просто "Hello"), но в 2x медленнее.

### 2. Batch перевод (TestLMStudio_BatchTranslation)

**Gemma-3-4B:**

**Gemma-3-12B:**

**Вывод**: 12B в **4x медленнее** на batch переводах. Для production лучше использовать 4B если нужна скорость.

### 3. Подсчёт токенов (TestLMStudio_TokenUsage)

| Размер текста | Gemma-3-4B | Gemma-3-12B | Разница |
|---------------|------------|-------------|---------|
| **Короткий (5 слов)** | 450ms (~29 токенов/сек) | 804ms (~17 токенов/сек) | 🔴 1.8x медленнее |
| **Средний (15 слов)** | 840ms (~71 токенов/сек) | 2.44s (~24 токенов/сек) | 🔴 2.9x медленнее |
| **Длинный (30+ слов)** | 1.69s (~97 токенов/сек) | 5.34s (~29 токенов/сек) | 🔴 3.2x медленнее |

**Итого по токенам:**
- **4B**: ~236 токенов за 2.98s (среднее: 993ms)
- **12B**: ~230 токенов за 8.58s (среднее: 2.86s)

**Вывод**: Чем длиннее текст, тем сильнее разница в скорости. 12B модель в **3x медленнее** на длинных текстах.

### 4. Сравнение производительности (TestLMStudio_PerformanceComparison)

**Batch перевод:**
- **4B**: 1.04s (1 API вызов)
- **12B**: 3.77s (1 API вызов)
- Разница: **3.6x медленнее**

**Отдельные переводы:**
- **4B**: 1.04s (3 API вызова)
- **12B**: 3.68s (3 API вызова)
- Разница: **3.5x медленнее**

**Вывод**: Интересно что для 12B модели batch и отдельные вызовы занимают примерно одинаковое время (~3.7s), в то время как для 4B batch чуть медленнее (1.04s vs 1.04s - практически одинаково).

## 🎯 Финальные выводы и рекомендации

### ✅ Когда использовать Gemma-3-4B:
1. **Production с высокой нагрузкой** - в 3-4x быстрее
2. **Real-time переводы** - 400-728ms приемлемо для пользователей
3. **Batch обработка большого объёма** - 204ms на сообщение отлично
4. **Ограниченные ресурсы** - меньше потребляет памяти и CPU

### ✅ Когда использовать Gemma-3-12B:
1. **Качество важнее скорости** - более естественные переводы
2. **Офлайн обработка** - когда можно подождать 2-5 секунд
3. **Критичные переводы** - для важной документации или контракты
4. **Маркетинговые тексты** - где важна естественность

### 💡 Гибридная стратегия:

```
IF (важный клиент OR сложный текст > 50 слов):
    использовать Gemma-3-12B
ELSE:
    использовать Gemma-3-4B (быстро и достаточно хорошо)
```
