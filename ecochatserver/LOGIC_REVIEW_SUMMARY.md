## ✅ Что НЕ трогали (и это правильно)

### 1. Delay через time.Sleep
```go
time.Sleep(time.Duration(ar.config.DelaySeconds) * time.Second)
```
**Почему не меняли:**
- Простота важнее оптимизации
- Delay обычно 1-2 секунды - не критично
- Асинхронный вариант усложнит код

### 2. Отсутствие timeout на создание агента
```go
agent, err := ar.getOrCreateAgent(ctx, isAuthorized)
```
**Почему не меняли:**
- Создание агента быстрое (<100ms)
- Context уже имеет timeout (IdleTimeMinutes)
- Риск зависания минимален

### 3. Эскалации в памяти (не в БД)
**Почему не меняли:**
- Это **intentional design** - эскалация это ephemeral state
- При рестарте сервера автоответчик должен снова начать работать
- Сохранение в БД добавит сложности без выгоды
