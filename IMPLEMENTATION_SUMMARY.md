## 🔧 Как это работает

```
┌─────────────────────────────────────────────────────────────┐
│ 1. Клиент: "какой у вас асортимент"                         │
└────────────────────────┬────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────────┐
│ 2. AutoResponder.ProcessMessage()                           │
│    → GenerateResponseWithTools(tools)                       │
└────────────────────────┬────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────────┐
│ 3. LLM (Gemini) анализирует:                                │
│    "Клиент спрашивает про ассортимент"                      │
│    → Возвращает functionCall:                               │
│      {name: "get_product_categories", args: {}}             │
└────────────────────────┬────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────────┐
│ 4. AutoResponder выполняет:                                 │
│    ExecuteTool() → storeClient.GetAllCategories()           │
│    → Получает реальные категории из API                     │
└────────────────────────┬────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────────┐
│ 5. AutoResponder отправляет результат обратно:              │
│    ContinueWithFunctionResult(result)                       │
└────────────────────────┬────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────────┐
│ 6. LLM формирует финальный ответ с реальными данными:       │
│    "У нас большой ассортимент!                              │
│     📂 Наши категории:                                      │
│       • Овощи и фрукты                                      │
│       • Мясо и птица                                        │
│       • Молочные продукты                                   │
│       ..."                                                  │
└────────────────────────┬────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────────┐
│ 7. Клиент получает ответ                                    │
└─────────────────────────────────────────────────────────────┘
```

## 🎉 Преимущества нового подхода

### Было (Regex):
❌ 100+ regex паттернов
❌ Каждую фразу нужно хардкодить
❌ Каждый язык добавлять отдельно
❌ Опечатки не работают
❌ Нет контекстного понимания
❌ Сложная поддержка (500+ строк кода)

### Стало (Function Calling):
✅ 2 функции (`get_product_categories`, `search_products`)
✅ LLM сама понимает намерения
✅ Все языки автоматически
✅ Опечатки и вариации работают
✅ Контекстное понимание ("чем занимаетесь?" → показывает продукты)
✅ Простая поддержка (~100 строк кода)

---

## 📝 Тестовые сценарии

### Должно работать:

| Запрос клиента | LLM вызовет |
|----------------|-------------|
| "какой у вас асортимент" | `get_product_categories()` |
| "what do you sell" | `get_product_categories()` |
| "есть ли молоко?" | `search_products(query="молоко")` |
| "do you have milk?" | `search_products(query="milk")` |
| "чем вы занимаетесь?" | `get_product_categories()` (контекст!) |
| "что у вас есть" | `get_product_categories()` или `search_products("")` |
