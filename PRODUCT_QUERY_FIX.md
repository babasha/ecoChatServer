# Исправление обработки запросов о продуктах

## 🐛 Проблема

### Диалог с клиентом:
```
Клиент: "какой у вас асортимент в целом"
Бот: "Ого, какой у нас ассортимент! 🤗 Мы стараемся, чтобы у нас было всё...
      * Свежие овощи и фрукты – каждый день новые поставки...
      * Мясо, птица, рыба...
      * Молочные продукты и яйца...
      [и т.д. длинный список из промпта]"
```

### Выявленные проблемы:

1. ❌ **Запрос НЕ распознан** как ProductQuery
   - Причина: опечатка "асортимент" vs "ассортимент"
   - Паттерн `какой\s*ассортимент` не срабатывает

2. ❌ **LLM отвечает из промпта**, а не из API
   - LLM берет информацию из статичного FAQ в промпте
   - Не делается запрос к API магазина
   - Клиент получает общую информацию, а не реальные товары

3. ❌ **LLM не понимает границы своих знаний**
   - Нет инструкции что делать при запросе о продуктах
   - LLM "придумывает" ассортимент из промпта
   - Не говорит "дайте я проверю"

---

## ✅ Решение

### 1. Улучшен паттерн распознавания

**Файл:** `llm/product_handler.go:43-44`

```go
// БЫЛО:
{`какой\s*ассортимент`, ProductQueryList},
{`ассортимент`, ProductQueryList},

// СТАЛО:
{`какой\s*(?:у\s*вас\s*)?[ао]сортимент`, ProductQueryList}, // Учитываем опечатку
{`[ао]сортимент`, ProductQueryList},
```

**Что изменилось:**
- ✅ Паттерн `[ао]` ловит и "ассортимент", и "асортимент"
- ✅ Добавлено опциональное "у вас" в середине запроса
- ✅ Теперь работает: "какой у вас асортимент", "ассортимент", "асортимент в целом"

### 2. Добавлена инструкция в промпт

**Файл:** `llm/autoresponder.go` (оба промпта)

```
⚠️ IMPORTANT - Product Queries:
• When customer asks about products/catalog/assortment - DON'T list from memory!
• Say: "Let me check current inventory! 📦" or similar
• System automatically detects product queries and fetches real-time data from store API
• Never invent product lists - inventory changes daily
```

**Что изменилось:**
- ✅ LLM знает что НЕ должна отвечать о продуктах сама
- ✅ LLM говорит "дайте проверю" и ждет
- ✅ Система автоматически перехватывает запрос и делает API call

## 🔄 Как это работает теперь

### Последовательность обработки:

```
1. Клиент: "какой у вас асортимент"
   ↓
2. DetectProductQuery() распознает паттерн [ао]сортимент
   → ProductQueryList
   ↓
3. HandleProductQuery() делает запрос к store API:
   - GetAllCategories() - получает категории
   - Или GetAllProducts() - получает товары
   ↓
4. Формируется ответ с РЕАЛЬНЫМИ данными из API
   ↓
5. Клиент получает актуальный список:
   "У нас большой ассортимент товаров!

   📂 Наши категории:
     • Овощи и фрукты
     • Мясо и птица
     • Молочные продукты
     [реальные категории из базы]"
```

### Если паттерн не сработал:

```
1. Клиент: "а что вообще продаете?"
   ↓
2. DetectProductQuery() НЕ распознает (нет в паттернах)
   ↓
3. Запрос идет к LLM
   ↓
4. LLM видит инструкцию:
   "DON'T list from memory! Say: Let me check..."
   ↓
5. LLM отвечает:
   "Дайте проверю что у нас есть! 📦"
   ↓
6. НО система НЕ делает API call (паттерн не распознан)
```

**Проблема:** LLM говорит "проверю", но система не проверяет!

## 🔧 Дополнительные улучшения (рекомендуются)

### Проблема: Фраза "что вообще продаете" не распознается

**Текущие паттерны:**
```go
{`что\s*продаете`, ProductQueryList},
```

**Не ловит:**
- "что вообще продаете"
- "а что продаете"
- "что конкретно продаете"

**Решение: Добавить более гибкий паттерн:**

```go
{`что\s*(?:вообще|конкретно|именно)?\s*(?:вы\s*)?продаете`, ProductQueryList},
```

### Проблема: "чем вы занимаетесь" может быть про продукты

**Добавить паттерн:**
```go
{`чем\s*(?:вы\s*)?занима(?:етесь|ешься)`, ProductQueryList}, // "чем занимаетесь?"
{`что\s*(?:вы\s*)?делаете`, ProductQueryList},              // "что вы делаете?"
```
