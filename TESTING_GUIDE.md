# Руководство по тестированию AI-тегов

## Что мы добавили

1. **Функция `inspect_website_page`** - позволяет AI "смотреть" на страницы сайта
2. **`data-ai-*` атрибуты** в HTML магазина - специальные теги для AI
3. **WebsiteInspector** - парсер который извлекает эти теги

## Как протестировать

### Тест 1: Вопрос о поиске товаров

**Откройте чат на https://enddel.com**

Спросите:
```
Как мне найти товар на сайте?
```

**Ожидаемое поведение:**
- AI должна вызвать `inspect_website_page("/")`
- Увидеть тег: `data-ai-element="search-bar"` с инструкцией
- Ответить примерно так:

> "Для поиска товаров воспользуйтесь поисковой строкой в правом верхнем углу хедера. Введите название товара и нажмите Enter для поиска."

### Тест 2: Вопрос о добавлении в корзину

Спросите:
```
Как добавить товар в корзину?
```

**Ожидаемое поведение:**
- AI увидит тег: `data-ai-action="add-to-cart"` с инструкцией
- Ответить:

> "Чтобы добавить товар в корзину, нажмите кнопку 'Add to Cart' на карточке товара."

### Тест 3: Вопрос о корзине

Спросите:
```
Как посмотреть мою корзину?
```

**Ожидаемое поведение:**
- AI должна увидеть страницу корзины
- Объяснить как туда попасть

### Тест 4: На английском

Спросите:
```
How do I checkout?
```

**Ожидаемое поведение:**
- AI ответит на английском
- Объяснит процесс checkout

## Как проверить что функция вызвалась

### Проверка логов Railway

1. Зайдите на Railway dashboard
2. Откройте логи сервиса `ecoChatServer`
3. Ищите строки:

```
[FUNCTION_CALLING] LLM вызывает функцию: inspect_website_page
[WEBSITE_INSPECTOR] Inspecting page: https://enddel.com/
[WEBSITE_INSPECTOR] Successfully inspected
```

Если эти строки есть - функция работает! ✅

### Проверка в ответе AI

Если AI дает **конкретные** инструкции про расположение элементов (например: "в правом верхнем углу"), значит она видит `data-ai-location` теги.

## Что делать если не работает

### Проблема 1: AI не вызывает функцию

**Симптомы:** AI отвечает общими фразами, не упоминает конкретное расположение элементов

**Решение:**
1. Проверьте что `GEMINI_API_KEY` настроен в Railway
2. Проверьте `STORE_API_URL=https://enddel.com` в Railway env variables

### Проблема 2: AI вызывает функцию, но не видит AI-теги

**Симптомы:** В логах есть `[WEBSITE_INSPECTOR]`, но AI не упоминает конкретные инструкции

**Возможные причины:**
1. React еще не отрендерил теги (SPA проблема)
2. Теги не задеплоены на магазин

**Решение:**
```bash
# Проверьте что магазин с тегами задеплоен
curl -s https://enddel.com | grep "data-ai"
```

Если ничего не нашлось - нужно задеплоить магазин с AI-тегами.

### Проблема 3: React SPA - теги не видны в исходном HTML

**Симптом:** `curl https://enddel.com` не показывает `data-ai-*` теги

**Это нормально!** React рендерит их на клиенте.

**Решение:** Нужен headless browser (Puppeteer/Playwright) или SSR.

**Временное решение:** Добавьте статичное описание в системный промпт (уже сделано частично).
